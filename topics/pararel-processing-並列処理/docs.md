# 想い
subprocess.Popenを使った並列処理は本来推奨される形ではない。
並列処理用のライブラリを使うべきである。

しかし、現実を模したコードを作りたいと思う時
可読性は非常に重要であり、
その観点で見た時に、今回の書き方は良いと今の所考えている。

# 考察
並列処理用ライブラリを使えば、一つの処理の中で別のオブジェクトの属性を参照したり書き換えたり、できるかもしれない。
subprocess.Popenでは、別プロセスに対しては、ファイルIOでしかコミュニケーションが取れない。
だけど、人間関係ってそういう物ではないかな。
他人の中身なんて直接いじれないし、
例えば AのためのプロセスとBのためのプロセスを起動して、Aのプロセス上でBを呼び出したとしても、それは本物のBではない。自分から見たBというだけ。

メタファーを作りたい自分としてはむしろ
好都合なのでは。
