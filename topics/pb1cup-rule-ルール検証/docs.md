# 概要
pickle ball の大会 pb1 cup で
ランダムペアでの対戦成績から
代表1名を選出するというルールでの開催があった

これに対して、運営側の意図的な操作があったのではないかと言う声が一部あった。

自分としては、仮に意図的な操作が全くなかったとしても、
このルールで最も強い選手が選択されるのか？
と言う疑問があった

# ルール詳細
- 11点マッチとする
- ペアおよび対戦はランダムで選択され、同じ人と2回ペアを組むことはないものとする
- 同じ人と対戦することはあるものとする
- 5対戦での得点率 ( 得点 / 総ポイント ) が最も高い選手を代表とする

# シミュレーション仕様
単純化したい

選手は30名程度を想定。
選手それぞれに1-100のLv(Level)を設定する
    正規分布に従う形にしたい。
ペアの総合レベルが高い方が勝利(point=11)とし、
負けた方は、勝った方とのレベル差分だけ引いたポイントを獲得とする。小数切り捨て。
ポイントはペアに同じだけ加算されるものとする。
デュースは想定しないものとする。
    例
        ペア1   敗北
            選手1 : Lv=80
            選手2 : Lv=30
            合計レベル = 110
            ポイント : 10 / 21
        ペア2   勝利
            選手3 : Lv=70
            選手4 : Lv=50
            合計レベル = 120
            ポイント = 11 / 21

        全体レベル = 230

5対戦のみの場合と、1000対戦の場合を比較したい

# 検証したい内容
本当にレベルが高い人が選ばれるのか。
    結果
    level=58が1位となり、やはりこの形式では公平性に欠けると思った。

# 選手リスト作成仕様
レベルをにするため正規分布
