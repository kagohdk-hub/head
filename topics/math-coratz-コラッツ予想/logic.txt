

コラッツ予想
	全ての数は
		0. 偶数：2で割る
		1. 奇数：3倍して1を足す
	を行うと最終的に1に到達する

def process(n: int) -> int:
	if n % 2 == 0:
		return n / 2
	else:
		return n * 3 + 1
def reverse_process(n) -> list[int]:
	reslist = [n * 2]
	if n - 1 % 3 == 0:
		if ((n - 1) / 3) % 2 == 1:
			reslist.append((n - 1) / 3)
	return reslist

問いへのアプローチ
	1. ルール通りに動かしてみる
	2. ルールの逆向きに動かしてみる
	3. ルール通りに動かした時の増減値に着目する
	4. グラフ的に捉える
	5. 背理法(1に絶対到達しない自然数Nを定義してみる)
	6. 素因数分解

見つけた性質
	1. 3の倍数は、全ての桁を合計すると3の倍数になる
	2. "奇数の場合"は連続しない。"偶数の場合"は連続し得る。
	3. 1からスタートする逆順プロセスで、基本的に2倍を続けることは無限にできるが、
		1を引いて3で割った数を分岐した時、その結果が3の倍数なら、そのブランチは2度と分岐しない。
		>	ブランチの根本の数字が、素因数に3が含むとき、そのブランチは2度と分岐しない。
		>	分岐元が 3**n + 1 の時、分岐した先のブランチは2度と分岐しない。
		3n * 2 = 3 * (2n) = 3m
	4. 逆に1からスタートして逆走した時、2倍ブランチからは2回に1回、1を引いて3で割る分岐が発生する
		(3n + 1) * 2 = 6n + 2 = (6n + 3) - 1 = 3(2n + 1) - 1 = 3m - 1
		(3m - 1) * 2 = 6m - 2 = 6m - 3 + 1 = 3(2m - 1) + 1 = 3x - 1
		# 2倍をすると 3n + 1 と 3n - 1 を繰り返す。 3n + 1 の時にブランチが分岐する。
	5. 全ての奇数は以下の３パターンのいずれかである。
		(1). 3 * 奇数
		(2). 3 * 偶数 + 1
		(3). 3 * 偶数 - 1
確かめたい点
	1. 1からスタートする逆順プロセスで、既出の数字が出ることはあり得るか。
		>	ブランチの最初の数は常に奇数であり、
	2. 1からスタートする逆順プロセスで、分岐した時、1の位が揃うのではないか
誤り
	1. 逆順の処理は、ルールに反する場合がある。
		逆順 : 40(39) -> 13(12) -> 4(3) -> 1
		だが 逆順を逆にしたとき
		1 -> 4 -> 13 -> 40 とはならない
		4は偶数のため2になる。

		逆順にするなら、1を引いて3で割った数が奇数の時だけ分岐できる　となる。

偶数プロセス : 減少する
奇数プロセス : 増加する

全ての数が、特定の増減パターンに当てはまり、全て最終的に減少する
ならば、
１に到達（しそう）
	現象プロセスは２で割るのため、最小の解は1となる

奇数 2n + 1 を ３倍して1を足すと必ず偶数になる
	(2n + 1) * 3 + 1
	= 6n + 3 + 1
	= 6n + 4
	= 2 * (3n + 2)
>>  つまり、３倍して1を足す　は連続しない。 (not 1.-1.)
	<-->    しかし、3倍して1を足し、2で割って(1.-0.)も増加する。
			2n + 1 < 3n + 2
			増加量  = 3n + 2 - (2n + 1)
					= n + 1
1.-0. の結果
	元の数字 = 2n + 1
	変換後の数字
		= ((2n + 1) * 3 + 1) / 2
		= (6n + 4) / 2
		= 3n + 2
	増減
		= 3n + 2 - (2n + 1)
		= n + 1
	増減率
		= (3n + 2) / (2n + 1)
		= ((2n + 1) + n + 1) / (2n + 1)
		= 1 + ((n + 1) / (2n + 1)) > 1

	3n + 2
		n = 偶数 >> 偶数 : n = 2m
		n = 奇数 >> 奇数 : n = 2m + 1

1.-0.-1. の結果が元の数字より増加しているか減少しているか
	1.-0. の結果が奇数 : n = 2m + 1
	元の数字 = 2n + 1 = 2(2m + 1) + 1 = 4m + 3
	変換後の数字
		= (((4m + 3) * 3 + 1) / 2) * 3 + 1
		= ((12m + 10) / 2) * 3 + 1
		= (6m + 5) * 3 + 1
		= 18m + 15 + 1
		= 18m + 16
	増減
		= 18m + 16 - (2m + 1)
		= 16m + 15
	増減率
		= (18m + 16) / (2m + 1)
		= (18m + 9 + 7) / (2m + 1)
		= (9(2m + 1) + 7) / (2m + 1)
		= 9 + 7 / (2m + 1) > 1
		# 1-0-1 で 約9倍 になる
1.-0.-0. の結果が元の数字より増加しているか減少しているか
	1.-0. の結果が偶数
	元の数字 = 2n + 1 = 2(2m) + 1 = 4m + 1
	変換後の数字
		= (((4m + 1) * 3 + 1) / 2) / 2
		= (12m + 4) / 4
		= 3m + 1
	増減率
		= (4m + 1) / (3m + 1)
		= (3m + 1 + m) / (3m + 1)
		= 1 + m / (3m + 1)
		# 微増
